# Аквариум с эволюционирующими рыбами — дизайн

Дата: 2026-11-26

## Зачем

Личный эксперимент ради интереса, не научная задача. Хочется **визуально наблюдать**, как в 2D-аквариуме эволюционируют рыбы: их тело, окраска и мозг (нейросеть), — под давлением хищника, борьбы за еду и выбора партнёра.

Успех: открываешь страницу, оставляешь на ускорении — и через какое-то время видишь, что рыбы стали вести себя осмысленно (убегают от хищника, ищут еду, находят партнёров), окраска популяции сдвинулась, мозги приобрели устойчивую структуру, а графики показывают, как к этому шло.

## Цели

- 2D-аквариум в браузере, живая анимация, ускорение времени.
- Рыбы с мозгом на NEAT (эволюционирует и топология, и веса) и генами тела/окраски.
- Замкнутая экосистема: водоросли → рыбы → отходы → удобрение → водоросли.
- Заскриптованный хищник.
- Половое размножение с выбором партнёра по узору (половой отбор против маскировки).
- Графики популяционных метрик, инспектор отдельной рыбы с живым мозгом, просмотр мозга-лидера (рыба с наибольшим числом живых потомков).

## Не-цели (сейчас)

- Эволюционирующий хищник — следующий этап; архитектура должна позволить заменить скрипт на NEAT-мозг без переделки.
- Влияние света, глубины, температуры. Свет только декоративный.
- Кормление извне (клик-корм) — **не делаем**, вся еда растёт в аквариуме.
- Сохранение/загрузка, мультиплеер, серверная часть, 3D.
- Научная строгость, воспроизводимость экспериментов, сравнение алгоритмов.

## Анти-цели (провал, даже если «работает»)

- Эволюция не идёт: поведение за долгий прогон не отличимо от случайного.
- Аквариум регулярно вымирает или взрывается популяцией без восстановления.
- Мозги бесконтрольно раздуваются.
- Нельзя понять, что происходит: нет графиков / нельзя заглянуть в рыбу.

## Ограничения

- Работает целиком в браузере, хостинг — GitHub Pages (статические файлы).
- Комфортно 100–200 рыб на обычном ноутбуке; при ускорении x10–x50 можно жертвовать отрисовкой (рисовать не каждый тик).

## Подходы

### Мозг (выбрал пользователь)

1. Фиксированная сеть, эволюционируют только веса — просто, но архитектура не развивается.
2. Фиксированный каркас с генами-выключателями — видно, что используется, но рост ограничен каркасом.
3. **NEAT — выбрано.** Старт с минимальной сети (входы → выходы), мутации добавляют нейроны/связи, каждый нейрон и связь стоят энергии. Прямо отвечает на желание «увидеть, какая архитектура становится устойчивой». Сложность — скрещивание разных топологий — решается innovation numbers из NEAT.

### Платформа (предложил Claude, пользователь согласился)

- **TypeScript + Canvas 2D, Vite, деплой на GitHub Pages — выбрано.** Нативно для браузера, быстро, без сервера.
- Python (pygame + pygbag/Pyodide) — отклонён: в браузере медленнее; шаблон PyCharm в проекте был случайным и удалён.

## Мир

- Прямоугольный 2D-аквариум (вид сбоку), стенки — твёрдые границы. Дно с несколькими камнями.
- Фон имеет цвет/текстуру (вода и дно), с которыми сравнивается окраска рыбы для маскировки.
- Симуляция идёт фиксированными тиками (детерминированный шаг), отрисовка отдельно; скорость x1/x10/x50/«максимум» + пауза.
- *(Решение Claude)* Симуляция крутится в Web Worker с самого начала: так она продолжает идти, когда вкладка в фоне, и «максимум» не тормозит интерфейс. Воркер шлёт снимки состояния рендеру и инспектору.
- *(Решение Claude)* Ориентир баланса: заметные изменения поведения/окраски — за ~30 минут на «максимуме». Не жёсткое требование.

## Питательные вещества и еда (замкнутый цикл)

- Общий запас «питательных веществ» в аквариуме постоянен; они переходят между формами:
  - **Растворённое удобрение** — поле на сетке (например 64×36 клеток), медленно диффундирует.
  - **Донные водоросли** — растут на дне и камнях, скорость роста зависит от удобрения в клетке. Много еды, но в предсказуемых местах.
  - **Планктон** — частицы, рождаются в толще воды там, где много удобрения, медленно дрейфуют; мало питательности каждая, но рассеяны.
  - **Рыбы и икра** — содержат питательные вещества в виде массы/энергии.
  - **Отходы** — рыба периодически испражняется пропорционально съеденному; частица медленно тонет и растворяется в удобрение. Мёртвые рыбы тоже разлагаются в удобрение.
- Затраты энергии рыбы на движение/мозг/жизнь возвращаются в удобрение (через отходы), чтобы цикл был замкнут.

## Рыба

### Гены (тело)

- Размер (влияет на скорость, затраты, сколько надо съесть, заметность).
- Максимальная скорость / сила рывка.
- Угол и дальность зрения.
- Порог энергии для готовности размножаться и сколько энергии отдаётся потомству.
- Продолжительность жизни задаётся базово + ген (умеренный разброс).
- Скорость мутаций — фиксированная (не эволюционирует) — решение по умолчанию.

### Пол (решение пользователя)

- Два пола, пол — случайно 50/50 при рождении.
- Пара — только самец + самка.

### Гены (окраска)

- Базовый тон (hue), яркость/контраст.
- Тип узора (однотонный / полосы / пятна / …), количество, второй цвет.
- Окраска **зависит от пола**: геном несёт гены окраски для обоих полов (или общий ген + «насколько выражено у самцов/самок»), каждая рыба проявляет свой вариант. Это позволяет эволюции сделать самцов яркими, а самок маскировочными (как у гуппи), но не навязывает этого.
- **Предпочтение партнёра**: «любимый» тон и узор + насколько привередлива. Тоже есть у обоих полов (выбирают оба), эволюция решит, кто станет разборчивее. Наследуется.

### Органы чувств (входы мозга)

- **Зрение**: 5–7 лучей веером вперёд (угол/дальность — гены). Каждый луч: расстояние до ближайшего объекта, тип (еда / хищник / рыба / камень), для рыбы — её «привлекательность» по своему вкусу. Объекты, похожие по цвету на фон, видны хуже (шум/меньшая дальность).
- **Боковая линия**: 360°, короткий радиус, чувствует быстро движущиеся объекты — направление (лево/право/спереди/сзади) и сила.
- **Обоняние**: градиент запаха еды (лево/право), запах тревоги (выбрасывается, когда хищник съедает рыбу).
- **Внутренние**: энергия, возраст, готовность к размножению.
- Итого ~20 входов + bias.

### Выходы мозга

- Поворот, тяга, «хочу размножаться» (порог).

### Энергия

- Постоянные затраты (жизнь) + движение (∝ скорость², размер) + мозг (∝ число нейронов и связей).
- Смерть: энергия = 0, старость, съедена хищником.

### Размножение

- Самец и самка, взрослые, обе с достаточной энергией, обе выдают «хочу» и обе принимают узор друг друга (по своим генам вкуса) — при соприкосновении.
- Обе отдают энергию → появляется кладка икры (1–N икринок, вкладываемая энергия делится).
- Икра лежит, может быть съедена хищником или рыбами, через время вылупляются мальки.
- Геном малька: скрещивание NEAT (совпадающие гены — случайно от родителя, лишние — от более «успешного», напр. более энергичного) + мутации тела, окраски, вкуса, мозга.

### Вымирание (решение пользователя: чем проще, тем лучше)

- Если не осталось ни рыб, ни икры — симуляция останавливается и показывает «Популяция вымерла» с кнопкой «Начать заново». Никакого автоматического подселения.

## NEAT

- Глобальный счётчик innovation numbers для связей/нейронов.
- Мутации: изменение весов, новая связь, новый нейрон (расщепление связи), отключение связи. Вероятности — на усмотрение реализации, настраиваются константами.
- Видообразования (species) нет (решение пользователя: проще). Отбор естественный, без fitness-функции и поколений.
- Рекуррентность разрешать не обязательно — решение за реализацией (feed-forward проще в визуализации).

## Хищник (этап 1 — скрипт)

- 1 хищник (кол-во — настройка), крупный.
- Патрулирует медленно; если видит рыбу в своём конусе зрения (маскировка снижает шанс заметить), бросается в рывок — быстрый, но с ограниченной выносливостью, потом отдых.
- После поедания — сытость, вялая охота некоторое время. Хищник не умирает и не размножается на этом этапе.
- Код хищника отделён интерфейсом «агент → действие», чтобы позже подставить NEAT-мозг.

## Интерфейс

```
┌──────────────────────────────┬──────────────────────┐
│                              │ Популяция  ▁▃▅▇▅▃▄▆  │
│        аквариум (canvas)     │ Ср. жизнь  ▂▃▃▄▅▅▆▆  │
│                              │ Потомство  ▃▃▄▄▅▄▅▅  │
│                              │ Ср. тон    ██████    │
│                              │ Частый узор  ≋       │
├──────────────────────────────┴──────────────────────┤
│ ⏸ ▶ x1 x10 x50 │ клик по рыбе → инспектор           │
└─────────────────────────────────────────────────────┘
```

- Метрики окраски и выживаемости — **отдельно по полам** (самцы / самки).
- **Графики во времени**: численность (и соотношение полов), средняя продолжительность жизни (умерших), среднее число потомков, средний тон окраски, самый частый узор, средние гены тела (скорость, размер), средний размер мозга, число нейронов и связей у мозга-лидера.
- *(Решение Claude)* **Поведенческие метрики** — чтобы видеть, что эволюция идёт, а не гадать: доля успешных побегов (рыба оказалась рядом с атакующим хищником и выжила), еда в единицу времени на рыбу, успешность спариваний. Это проверка анти-цели «поведение не отличимо от случайного».
- **Инспектор рыбы** (клик): камера следует за ней, лучи зрения рисуются, мозг показан графом с живой активацией нейронов, гены, возраст, энергия, число потомков.
- **Мозг-лидер**: граф мозга рыбы с наибольшим числом живых потомков, и как менялись размер/структура мозга-лидера со временем.

## Оставлено реализатору

- Конкретные числа баланса (затраты, скорость роста водорослей, вероятности мутаций), размер сетки, количество лучей — подбираются при настройке, вынесены в один конфиг.
- Пространственный индекс (сетка) для быстрого поиска соседей.
- Библиотека графиков (или самописные спарклайны), стиль отрисовки рыб/узоров.
- Структура кода; требование — симуляция отделена от отрисовки и тестируема без браузера.
